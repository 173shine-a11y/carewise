# Days App Privacy Policy

This repository hosts the privacy policy for the **Days** mobile application.

## 📱 About Days

Days is a personal task management app designed to help users organize their daily activities, set reminders, and track birthdays.

## 🔒 Privacy Commitment

**NO PERSONAL INFORMATION WILL BE GATHERED THROUGH THIS APPLICATION.**

Days is built with privacy by design:
- ✅ All data (tasks, reminders, birthdays) is stored **locally on your device only**
- ✅ No accounts or sign-ups required
- ✅ No analytics or tracking tools
- ✅ No data is sent to any external servers
- ✅ No personal information is collected, stored, or shared
